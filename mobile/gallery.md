# Gestalt Mobile screenshot gallery

This gallery follows the complete browser journey: passkey onboarding,
workspace and session setup, Chat interactions, supervised plans, Git,
Scratchpad, and device management. Every image was captured from the real
Gestalt Mobile interface with Playwright at a phone-sized viewport. Relay data
was deterministic and contains no private workspace or authorization state.
